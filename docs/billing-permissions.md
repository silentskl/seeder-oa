# AR/AP delegated billing permissions
Super administrators retain implicit access. Existing Entity admins must receive an explicit finance.billing.manage grant from Accounts & Permissions before billing access; no migration backfill. Active Entity membership is required. Revocation removes API and attachment access on subsequent requests. The grant permits both AR and AP ledger, invoice import/review, settlement submission and approval subject to existing independent-review and bank verification guards. Configuration additionally requires Entity admin role; supplier/customer writes, contracts, HR and permission management are independent. Approved counterparty records needed for invoice review are available to the billing manager. Background service-token and signed inbound processing remain unchanged. Before deployment test two Entities, grant/revoke, disabled membership, direct file download, invoice and settlement mutations, party-only denial, and two-user independent approval.
